# Reference figure policy

Reference figures are style evidence, not scientific evidence.

## Extract a style fingerprint

Record only what is useful and transferable:
- visual density: sparse / medium / dense
- background and panel treatment
- typography hierarchy
- palette roles (not exact colors unless requested)
- stroke and arrow character
- corner/shape language
- icon abstraction level
- panel labeling
- whitespace rhythm
- annotation style

## Do not transfer

Do not copy:
- scientific entities or labels
- arrows/topology
- numerical content or plots
- exact layout geometry
- distinctive illustrations/icons
- watermarks/logos
- visual elements that imply unsupported science

## Reference conflict rule

If a reference's layout conflicts with the semantic contract, the semantic contract wins. If multiple references disagree, synthesize a restrained common grammar rather than making a collage of styles.

## Existing-figure redesign

When the user's own figure is the reference, separate invariants from editable properties. Preserve scientific content/data; redesign hierarchy, spacing, typography, routing, palette, and icon simplification only within those invariants.
