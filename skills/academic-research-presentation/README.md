# Academic Research Presentation Skill — V3

For:
- paper reading / paper presentations;
- lab/group meetings;
- advisor research updates;
- technical scientific talks.

## V3 focus

V2 successfully pushed decks toward main figures/tables, but two failure classes
remain especially dangerous in automated research slides:

1. invented or directionally wrong custom flowcharts;
2. incomplete/contaminated screenshots of paper figures.

V3 adds hard gates:

- Diagram Safety Gate
- Source Visual Acquisition Gate
- explicit node/edge diagram specs
- arrowhead verification after render
- source visual preflight before slide layout
- semantic completeness checks for axes/legends/panels
- one hero visual per slide by default
- prohibition on clipping evidence merely to save slide count

## Philosophy

**Evidence before diagrams.**
**Semantic completeness before aesthetic cropping.**
**Scientific objects define layout.**
**Canvas-first, not box-first.**

Pair with a base PPTX/slides implementation skill for generation/rendering.
