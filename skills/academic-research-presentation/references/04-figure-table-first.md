# Figure / Table First Protocol

## Visual Evidence Pass

For PAPER_READING, inventory all:
- figures/panels;
- tables;
- algorithms;
- equations;
- qualitative examples.

Classify:
- Tier A — narrative-critical
- Tier B — supporting
- Tier C — backup

Name:
- MAIN_METHOD_FIGURE
- MAIN_RESULT_FIGURE_OR_TABLE
- MAIN_ABLATION_OR_ANALYSIS
- HERO_EVIDENCE (2–5)

Before storyboarding, Tier A/B visuals MUST go through
`10-source-visual-acquisition.md`.

## The evidence is the slide

For main result/method evidence:
- let the visual dominate;
- use direct annotations;
- use a message title;
- add only the text required to read and interpret it.

Do not shrink evidence to make room for cards.

## One hero visual by default

For Tier-A visual:
one major visual per slide is the default.

Split complicated evidence across slides.
Reuse a central figure with different annotations when useful.

## Six-step explanation

1. scientific question
2. reading grammar
3. where to look
4. literal observation
5. interpretation
6. caveat

## Main table

Preserve exact values and relevant baselines.
Rebuild as native table when exact data are available.

Show:
- metric + direction;
- strongest baseline;
- ours;
- key delta;
- uncertainty;
- exceptions.

## Plot

Preserve complete axes/legend/data region.
Directly annotate the comparison being discussed.

## No screenshot dumping

A paper page crop that includes surrounding body text/header/caption fragments
is not an acceptable “figure”.

A crop missing axes/legend is also unacceptable.

## Visual reading path

Question → read → look here → observation → interpretation.

## QA

[ ] complete scientific visual
[ ] source traceable
[ ] labels readable
[ ] no page furniture contamination
[ ] no clipped axis/legend/data
[ ] title states message
[ ] key comparison annotated
[ ] interpretation matches evidence
[ ] exceptions preserved
