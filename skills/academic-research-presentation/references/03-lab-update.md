# LAB_UPDATE Mode

## Goal
Make the current research state inspectable and enable decisions.

Prioritize:
- new experimental evidence;
- diagnostic plots;
- negative results;
- failed attempts;
- uncertainty;
- competing hypotheses;
- blockers;
- next discriminating experiment.

## Default arc
current question → hypothesis → exact experiment → result → diagnosis →
alternative explanations → next test → decision.

## Background
Use only enough recap to restore context. Do not spend large portions of a
recurring group meeting retelling the project.

## Negative results
For a failed experiment show:
- expected outcome;
- exact intervention/configuration;
- observed evidence;
- diagnosis;
- competing explanations;
- next experiment that would distinguish them.

## Visual preference
Use aligned plots, tables, traces, and concrete examples.
Do not convert research progress into “Completed / Ongoing / Next” cards.

## Decision quality
Research progress means uncertainty reduced, hypothesis supported/rejected,
bottleneck localized, or capability demonstrated—not simply code implemented.
